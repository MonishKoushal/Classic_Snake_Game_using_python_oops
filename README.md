Classic_Snake_Game_using_python_oops:


A classic Snake Game developed using Python and Turtle module, following Object-Oriented Programming principles.

OOPS Concepts Used
- Classes and Objects
- Inheritance
- Encapsulation
- Abstraction

Files Description
- main.py – Game loop and event handling
- snake.py – Snake movement logic
- food.py – Food generation logic
- scoreboard.py – Score display and game over logic

How to Run
1. Install Python 3
2. Run `main.py`
